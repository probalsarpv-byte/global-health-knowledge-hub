## 🌟 Core Architecture & Standards

1. **Three-Tier Depth Hierarchy:** Every available chapter offers full progression across Foundation, Academic, and Advanced/Research tiers.
2. **First-Class Bilingualism:** Complete English and Bengali (`বাংলা`) parity with medical terminology, Latin binomials, and cultural adaptations.
3. **Vancouver Numeric Citation System:** Bracketed citations (`[1]`, `[2]`) linked to verified peer-reviewed publications and clinical practice guidelines (AND, ASPEN, ESPEN, KDIGO, Endocrine Society).
4. **Calculations & Formulations:** Pure mathematical implementations of Mifflin-St Jeor, Penn State, UUN Nitrogen Balance, Holliday-Segar, Ganzoni, and electrolyte corrections.
5. **Rule of Authenticity:** Only thoroughly implemented chapters are marked `status: 'available'`. Planned chapters are clearly indicated.

## 🛠️ Local Development & Verification

```bash
# Clone repository
git clone https://github.com/probalsarpv-byte/global-health-knowledge-hub.git
cd global-health-knowledge-hub

# Install dependencies
npm install

# Run development server
npm run dev

# Run quality checks
npm run lint       # ESLint with --max-warnings=0
npm run typecheck  # TypeScript compiler check
npm run test       # Vitest unit & integration tests
npm run build      # Production build
```
